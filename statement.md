Project Statement

Problem Statement

In a small convenience store, preparing a bill manually can take extra time and can also lead to simple calculation mistakes. The purpose of this project is to make a basic Python program that can calculate a customer's bill from the products and quantities entered by the user.

Scope

The project covers product selection, cart management, subtotal calculation, discount calculation, tax calculation, payment checking, and receipt display.

It is a console-based project. It does not use a database, online payment system, barcode scanner, or graphical interface.

Target Users

The main target user is a small shopkeeper or a student who wants to understand how a simple billing system can be built using Python.

High-Level Features

Product list

Add products to cart

View cart

Automatic subtotal

Discount calculation

Tax calculation

Payment and change calculation

Receipt generation

Basic input validation

Basic calculation tests

Why I chose this project

I chose a convenience store bill calculator because it is a problem that is easy to understand and has a clear input and output. It also gives me a chance to use several Python topics together instead of writing only one small program.

Limitations

The current version keeps the data only while the program is running. If the program is closed, the cart is cleared. Product prices also have to be changed directly in the Python file.

Future Improvements

If I continue the project later, I can add stock management, a file/database for saving products, a graphical interface, barcode scanning, and different types of bills.
